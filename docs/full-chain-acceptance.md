# BioTrip 全链路升级验收

日期：2026-10-19。实现保留 React 19 / vinext / Workers / D1 / Workflows / 百炼，升级依据为用户确认的全链路计划。

## 已交付

- 移动端今天、调整、发现、分层设置，全屏旅程助手；新建、引导、重排、减负共用页面动效。
- 当地日持久自评，今日、重排、快速调整、助手共用；WHOOP 未连接隐藏设备模块。
- 零外部调用快速调整、前后图表预览、确认采用、独立记录、真实反馈进入后续排序。
- 固定预约完整区间、交通缓冲、实际进度、并发版本、午夜过期、历史恢复保护；移出活动进入待安排。
- 八类 FlyAI 参数和结果契约、按意图搜索、查询回执、成功结果去重、未知结果不盲目重试、后台会话清理。
- 六轮有界 Agent 执行、结构化问题/商品/差异/清单内容、统一记忆开关、候选确认和实际保存状态。
- 重排使用节奏图卡、当日五档感受、预约卡片、生成前确认；只有一个默认折叠的补充要求。生成后进入独立前后时间轴，采用后才写入实际行程。
- 预约修改以活动 ID 提交影子授权，服务端保留完整时长、身份和进度；同名预约独立修改，旧文本异常从实际行程恢复。

## 真实线上验收补充

真实航班查询返回 6 个带出发、到达时间与飞猪来源的结果；供应商未给票价的条目保留未知，不推测价格。登录状态下的 WHOOP 图形已加载；本报告不保存个人读数。

一次旧历史会话继续发送时返回“这段对话不存在”。目前没有足够证据确定原因，未自动重建或删除历史记录。随后新的独立会话连续两轮问答成功，完整刷新后两轮消息均恢复；本地同样验证了两次请求使用同一会话且无删除请求。此现象保留为未定位记录，不宣称已修复旧会话。

语义检索曾把未含茶饮信息的酒店和景点当成喝茶选择。该真实样例用于补充产品证据过滤、来源分类和明确搜索范围的约束；不把模型的一句“已找到”作为检索验收通过的依据。八类工具通过契约测试，不等于八类供应商都完成了本轮线上调用。

最终复测中另发现模型返回不支持的 action 格式，服务端拒绝执行。此轮没有呈现可验证的查询回执，因此不计作成功搜索。已补充一次格式纠正、真实回执摘要和失败/无匹配区分。随后本地真实模型完成相同请求的回复并持久保存；仅一条语义查询回执，本地 FlyAI 未配置，界面准确显示检索未完成，因此不计作真实商品检索成功。

最终生产版本 `e8507fe6-96ed-4fc2-be73-9b850158568c` 再次使用同一线上会话执行明确的单次语义查询。浏览器完成回复并显示“这次没有匹配结果”及来源证据筛选说明：返回商品没有明确茶饮服务信息，普通酒店/景点未作为匹配结果展示，也没有自动扩大搜索。此项验证了真实供应商响应、服务匹配筛选和诚实空态；没有找到合适产品，不宣称找到了茶馆。正式客户端资源与发布版本一致。
