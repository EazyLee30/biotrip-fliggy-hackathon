# 验证说明

## 自动化检查

```bash
pnpm exec tsc --noEmit
pnpm test
pnpm lint
pnpm run build:vinext
```

截至 2026-10-23，486 项测试通过。GitHub Actions 在推送与 Pull Request 上执行安装、类型检查、测试、ESLint 和生产构建，最新结果见 [CI](https://github.com/EazyLee30/biotrip-fliggy-hackathon/actions/workflows/ci.yml)。

测试覆盖账号隔离、WHOOP 授权刷新、来源约束、规划任务、行程版本、预约保护、助手工具、身体反馈、素材指纹与影片字节范围。第三方 API 的真实调用需要自己的有效服务配置，测试通过不等于供应商当前可用。

## 在线体验

1. 使用独立测试账号登录，设置旅行偏好并创建旅程。
2. 生成规划，核对日期、来源与固定安排。
3. 记录当下感受，预览并确认调整。
4. 记录体验反馈，刷新页面确认保存。
5. 在助手中查询安排、管理清单，并确认一项行程操作。
6. 分别验证可选的 WHOOP 连接和高德路线依据。

官网发布已完成 35 项线上检查，浏览器验证了影片播放与章节跳转。既有真实验证覆盖百炼规划、FlyAI 查询与有依据的空结果、本地高德路线及确认保存。

## 验证边界

- 浏览器移动端仿真已覆盖窄屏、短视窗和键盘区域；不能替代实体 iPhone、Android、主屏幕模式和系统分享的验收。
- 最新版本没有重新执行全部外部付费流程，生产真实路线会诊仍需单独验证。
- WHOOP 接入受开发者应用的沙盒资格与平台审核限制。
- 影片中的 WHOOP 数据为本人授权的历史记录，主观疲劳变化为演示情境。
- 测试账号、原始接口输出、截图批次和制作过程保留在本地，不随公开源码提交。
