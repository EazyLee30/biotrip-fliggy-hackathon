- 已有行程封面缩到手机 150px、宽屏 170px；安排改为紧凑单列时间轴，说明最多两行，去掉重复图标与每个活动的装饰大图。版本历史、生成说明和核验记录收入“更多”。日期条固定、保存各日阅读位置、提供“回到今天”，选中日期在横向条居中。旅途中的“接下来”使用目的地当地日期与开始时间，不能据此推断活动完成。
- 按用户指示取消香港、上海、京都候选实景；首页及新分享封面使用生成氛围图。旧杭州公开快照所需素材与许可记录保留兼容。背景使用 640/1280 两档 image-set；商品图片继续沿既有真实 API 图片、懒加载和稳定占位比例。
- 任务运行与进度页开关分开。收起进度后继续跟踪，任务条在行程、节奏、发现和我的都可找到。结果保存只更新所属旅程列表，不自动切换另一段旅程、页面或弹出候选确认。点击结果前保存当前草稿；推荐组件保持挂载，保留横向阅读位置。隐藏页面降低到至少 15 秒读取，回前台立即同步，不重新提交。补齐提交等待、提交失败后导航恢复、停止任务状态和未处理候选保护。
- 页面导航接入同文档浏览器历史，详情返回恢复实际父页面及滚动。弹窗管理自己的历史项，系统返回先关闭最上层；关闭按钮、下拉、键盘与焦点恢复沿用共享 Modal。修正弹窗关闭与异步页面跳转竞态：先完成历史回退，再保存及跳转，避免刚进入行程又退回我的。活动编辑与个人档案导航使用“保存并离开／继续编辑／放弃修改”，失败保留本地输入。
- 分享分为选内容、看预览、发布后分享或保存。增加 40 字自定义标题、公开推荐勾选、明信片与行程手记。明信片为 1080×1440，至多 3 条短推荐；详细或长内容明确转为分页手记，正文不压小或截断。预览、公开页和 PNG 同用经确认的不可变快照，记录所属行程版本。旧快照继续读取，默认隐私开关保持，健康数据不进入公开输出。服务端验证模板、标题、选中推荐所属关系及版本并发。
- 来源增加可选结构化类型：飞猪商品、地点资料、专题资料、普通参考。新生成商品写入飞猪商品类型；当地检索信息无法确认层级时写普通参考，旧数据不猜测具体地点。新增活动可引用当前旅程已检索的来源 URL，后台拒绝任意外链关联；详情仅在明确关联商品时展示该商品图片。手动编辑、排序及版本快照保留引用，分享仅映射获准字段。
- 在现有私有任务事件上汇总提交、首批非空推荐、编排完成、结果就绪时刻，精度为秒。首次结果就绪单独记事件，后续用户采用候选不会改写这一耗时；游标读取也能返回完整汇总。不通过额外模型调用采集。已有三路独立检索继续并行，首批推荐分批返回。
- 我的移除重复守护说明，长期偏好、记忆与分享管理折叠；身体读数集中在节奏，设备与账户管理留在我的。异常列表响应留在分组错误状态，避免整页因空数组缺失崩溃。
