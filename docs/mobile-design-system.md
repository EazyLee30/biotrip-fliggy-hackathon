# BioTrip 移动端体验规范

2026-10-19，全链路升级实现。组件所在目录：`src/app/components/planner`、`src/app/components/ui`、`src/app/components/agent`。

## 信息层级

- 主导航：今天、行程、发现、我的。行程为一级目的地，保留主导航；旧 `#adjust` / `?view=adjust` 兼容转入行程。
- 今天：紧凑目的地信息 → 正在进行/下一站 → 当日自评与 WHOOP 摘要 → 快速调整 → 今日路线 → 负荷与反馈。今天的内容始终使用目的地当地日期，与行程日期选择独立。
- 行程：旅程信息、日期条、完整时间轴；直接进入调整今天或整段重排，收藏清单与历史版本从这里查看。标签切换保留日期和滚动位置，取消调整回到实际来源。
- 身体记录：WHOOP 完整仪表盘唯一归属。首页只展示恢复、睡眠、记录时间与同步状态；设备设置链接同一个详情页。未连接不展示首页设备摘要，身体记录页仍可进入，不依赖旅程是否创建；有旅程时展示该旅程的自评与历史。
- 调整：今天减负从首页与行程页发起，整段重排从行程页发起。减负使用感受、方案、预览三个页面，已有当日评分跳过重复询问；最多三个有效方案。取消建议释放规划任务。
- 重排：节奏图卡 → 当日五档感受 → 预约卡片 → 生成前确认；文字只有默认收起的“补充要求（选填）”。预约通过日期条和时分选择器编辑，同名活动使用稳定 ID，编辑未保存不能越过下一步。完整候选在独立页面按日期对照，手机切换前后时间轴、宽屏并排，确认才采用。进行中和完成的活动不显示编辑入口。
- 旅程助手：全屏，返回、旅程名、更多菜单。问题、商品、清单和行程差异使用结构化内容，历史文本继续渲染 Markdown。主页面顶部可进入助手，不再用悬浮入口覆盖活动操作。
- 发现：目的地搜索、服务快捷入口、实际来源卡片。合并地点及本地服务，支持比较、收藏、来源查阅；加入行程由助手生成修改预览并确认。
- 我的：旅行习惯、旅行记忆、设备与数据、账号与隐私逐层展开。设备与数据负责连接、授权与同步，不重复展示完整仪表盘。助手中的记忆入口复用同一个管理页面。

## 视觉与组件

| 元素 | 规范 |
| --- | --- |
| 画布/正文 | 暖白 `#f8f7f2`、森林绿 `#203d35`；正文 16px，输入 16px，避免 iOS 自动缩放 |
| 主操作 | `#234a3b`，最小高度 48px；主向导 54px；一屏一个主要推进动作 |
| 辅助色 | 苔绿用于选择和休息；陶土色用于交通或费用提示 |
| 图像 | 地点与商品使用已核验来源图；没有实景时明确标注“旅行氛围图”，不冒充商品图片 |
| 分组 | 留白和细分隔线；只有可选方案、下一站、商品等对象使用完整卡片 |
| 身体状态 | 五档表情自评；设备未连接时隐藏 WHOOP；来源、时间、单位保留短标签 |
| 图表 | 负荷条按活动、已知交通、休息分段，标明估算；未知交通不显示为已核验的 0 分钟；历史使用真实自评记录 |
| 边界状态 | 加载预留尺寸、错误可重试、未知价格保留未知、过期/版本冲突不冒充成功 |

## 动效和依赖

当前锁定解析版本为 Motion 14.3.0、Base UI 1.9.0、Lucide React 1.59.0、Recharts 3.10.1，具体树由 `pnpm-lock.yaml` 固定。

- `MotionProvider` 按需加载特性，首次引导、新建、调整、重排共用 `StepTransition`。
- 按压约 120ms，页面进入/退出约 240ms；遵守系统减少动态效果设置。
- Base UI 提供开关、菜单及助手全屏对话容器的焦点管理；Lucide 提供统一图标。
- Recharts 仅在展开感受历史后加载；简单负荷条和圆环使用轻量 SVG/CSS。
- 助手监听视觉视口处理软键盘；底部操作考虑安全区，向导不叠在底部导航上。
