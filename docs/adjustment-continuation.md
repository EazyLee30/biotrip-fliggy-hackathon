- 新增 `itinerary` 数据授权。舒缓货架与出行阶段只允许 `trip + itinerary`，编排不能接触 WHOOP 原始记录；仅枚举身体需求进入编排。拒绝请求中未声明的隐藏资料。
- 行程生成 schema 和宽松解析接入活动类型、强度、计划时长与移动方式；费用、距离不由模型输出。
- 实景绑定进入生成结果，已核验图片用于旅程主封面、书架小封面、活动缩略图。无图片或加载失败时保留原封面/文字。新增城市 POI 目录阶段，可独立降级；以确定性名称匹配绑定实景。
- 普通 Tab 切换立即发生，草稿队列与账户刷新在后台执行；移除内容区全局 inert。跨旅程切换与显式保存仍等待草稿以防错写。

- 生成行程的 `poi_catalog` 与其他检索并行、允许降级；已核验景点名称供编排使用，图片与链接由代码绑定。
- 城市选择后延迟预取；旧行程在「更多 · 旅程说明、版本与来源」手动补图，不调用模型。补图保留固定安排、草稿与既有图片，以版本和后台任务检查防止并发覆盖，写入后保留历史快照。
