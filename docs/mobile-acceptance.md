# BioTrip 手机验收

更新：2026-10-04。本表只记录已观察的结果；桌面手机尺寸模拟、Playwright WebKit 和 iOS 模拟器都不等于实体手机通过。

## 环境与准备

用独立测试旅程，避免改动正在使用的真实安排。记录设备型号、系统版本、浏览器版本、普通 Safari / 添加到主屏幕 / 应用内浏览器及验收时间。第一次分享默认不公开身体记录、精确日期或固定预约。不开启新的 WHOOP 授权，不为手势验收触发生成。

电脑发现的两台 iPhone 当前均不可用，未建立实体设备测试连接。实体设备可用后在 `https://biotrip.eazylee.si` 测试；不需要把账户密码、WHOOP 数据或手机日志发到聊天中。

## 操作与通过条件

| 项目 | 操作 | 通过条件 | 实体机状态 |
| --- | --- | --- | --- |
| 字母侧栏 | 创建旅程 → 目的地 → 国内；手指按住右侧字母条，从 B 连续滑到 H，再反向滑到 C，随后直接点热门 | 连续显示对应字母并滚到相应分组；放手不选城市；点热门回热门；主页面不跟着滚 | 待验 |
| 国际地区 | 切国际，点日韩 → 欧洲 → 热门，选择城市；关闭后重新打开 | 列表与地区对应，选择回表单；不会无故跳到应用外 | 待验 |
| 地区弹窗下拉 | 从标题顶部或抓手向下拖约 100px；再试短距离拖动、横向滑动 | 足够下拉关闭；短拖回弹；横向滑动不关闭；恢复原页面滚动与焦点 | 待验 |
| 日期弹窗 | 选去程与返程，再从顶部下拉关闭；重新打开确认日期；在日历内容中滑动 | 下拉关闭不误确认日期；日期按实际确认规则保留；内容滚动不被关闭手势抢走 | 待验 |
| 时间滚轮 | 编辑预约，分别滚动日期、小时、分钟；快速滚后立即点确认；切后台再回来 | 停在高亮值后才确认；滚动中显示等待选择，不写入临界旧值；手指纵滑不横移 | 待验 |
| 长按拖动 | 在独立旅程进入编辑，长按灵活活动把手约半秒，拖到另一灵活活动；取消一次，再保存一次 | 长按激活、放手换序；取消不写库；保存后刷新顺序保留；固定活动不可拖动 | 待验 |
| 边缘滚动 | 编辑超过一屏活动，拖动到编辑区域底边，再到顶边 | 区域连续滚动、目标跟随且可到屏外活动；不滚动整个背景页面 | 待验 |
| 手势取消 | 拖动中切应用或来电/系统手势打断，再返回；点击关闭再重新打开编辑 | 拖动状态清除，按钮恢复可用，没有残留遮罩或意外保存 | 待验 |
| 返回层级 | 节奏页滚下去 → 睡眠详情 → 返回；再我的 → 身体记录与节奏 | 详情回原节奏位置；个人页入口从顶部打开节奏 | 待验 |
| 大字号与键盘 | 打开系统大字号；在 320–390px 等效宽度输入预约内容、搜索城市 | 无横向溢出；键盘不挡确认；输入不会无故放大页面；关闭键盘可继续 | 待验 |
| 系统分享链接 | 发布测试分享 → 系统分享；取消一次；再分享到自己的本地备忘录等接收目标 | 原生面板出现；取消不报错；再次打开正常；接收内容只有已公开标题和链接，能打开 | 待验 |
| 海报分享 | 制作海报后点系统分享图片；保存到照片；再长按预览尝试保存 | 分享的是 PNG 而非 Blob 地址；图片可打开且中文完整；长按或保存链接至少有一条可用 | 待验 |
| 不支持分享 | 应用内浏览器中尝试分享；或浏览器拒绝文件分享能力 | 明确提供复制链接、保存各张图片或浏览器菜单；不出现未处理错误 | 待验 |
| 连点分享 | 快速点系统分享按钮两次 | 仅一个分享调用/面板，不报“另一个分享正在进行” | 待验 |
| 撤回分享 | 保存测试海报后撤回链接，重新打开链接 | 链接失效；界面明确已保存海报不能远程撤回 | 待验 |
| 图片许可标注 | 杭州实景封面、分享页、导出海报 | 显示杭州断桥、Suicasmo、CC0 与拍摄日期；其他城市不套用杭州实景；商品图独立标注 | 待验 |

## 回报格式

只需回复：设备/系统/浏览器、通过的项目名称、失败项目的操作步骤与看到的结果。不要发送账户密码、完整 WHOOP 记录或收件人的个人资料。可以在本表“待验”栏记录通过、失败或不支持，并注明设备；不支持但替代操作可用时，记录为“替代路径通过”，不能写成原生分享通过。

## 自动化与模拟器证据

代码回归验证了侧栏/弹窗/排序状态机、取消保护、分享能力拒绝与取消、文件载荷和来源许可指纹；每次发布的测试总数见执行记录。

iOS 26.3 模拟器已启动并打开 Safari，但系统页面中文也出现缺字，且未完成本应用触摸或原生分享操作。没有实体设备接入，因此本表实体机状态全部保留待验，不能据此出具通过结论。

本批 299 项代码测试通过。桌面 Chrome 使用本地专用 QA 旅程完成杭州许可封面选择、分享发布、两张海报生成、首张 PNG 下载；公开页 200 且包含作者和 CC0，测试分享撤回 200 后公开页 404。下载证据：`output/playwright/licensed-hangzhou-poster.png`。未向其他人发送内容。

手机尺寸 WebKit 只读夹具能打开旅程及许可封面选择；本地 HTTP 下实际登录受 Secure 会话 Cookie 限制，夹具分享 POST 未成功隔离，未完成分享验收。没有修改生产认证策略。上述结果不代表 iPhone 系统分享面板、照片保存或长按拖动已通过。
