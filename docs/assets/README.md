# 素材来源与许可

本目录保留正式产品素材所需的来源与许可记录，不包含设计探索稿或开发截图。

- `asset-register.json`：已交付氛围图、字体和目的地素材的登记信息。
- `licenses/hangzhou-broken-bridge.json`：杭州西湖断桥照片的作者、来源、许可与文件指纹。
- `licenses/hangzhou-broken-bridge-original.jpg`：用于来源核验的原始照片。
- `licenses/*-source.html` 与 `licenses/cc0-1.0-legalcode.html`：归档的作品来源与许可文本。
- Plus Jakarta Sans 字体许可位于 [`public/fonts/LICENSE-jakarta.txt`](../../public/fonts/LICENSE-jakarta.txt)。

素材指纹由 `src/lib/visual-assets.test.mjs` 校验。正式产品中的展示版本位于 `public/destinations/` 与 `public/ambience/`。

README 横幅 `public/brand/readme-banner.webp` 使用内置 ImageGen 绘制，图标参考项目原有的 `public/biotrip-icon.svg`。横幅湖景为 AI 创作，不作为真实地点或商户照片。官网与影片中展示的 WHOOP 记录经本人授权，界面标明历史记录。

第三方 Skill 保留 [`bailian/flyai-search-skill/LICENSE`](../../bailian/flyai-search-skill/LICENSE)。公开源代码不改变第三方素材各自的许可。
