# BioTrip · 飞猪黑客松

BioTrip 是一个移动优先、可安装到手机主屏幕的旅行行程自适应项目。它根据用户当天的身体状态和行程负荷，提出清楚、可撤销的调整建议；用户确认后，修改 TREK 中的真实行程，并在需要替换景点或体验时通过 FlyAI 查询飞猪商品。

## 核心演示

东京三日行程 + 一份低恢复状态快照 → BioTrip 找出超负荷的步行安排 → 保留已预订和必须参加的项目 → 提议改乘公共交通/出租车、加入恢复时间、移动一个弹性景点 → 用户查看变更和理由并确认 → TREK 行程实时更新，FlyAI 展示可预订替代选项。

BioTrip 的判断采用可解释的规则，健康数据不交给大模型作决定。所谓 P/J 风格是一个“行程灵活度”滑杆，用来设定行程偏好，不给用户贴 MBTI 标签。

## 产品形态

- 以 TREK 作为行程、地图和旅行状态基础。
- 通过 TREK 插件 SDK 增加 BioTrip 行程页面；优先复用 TREK 的手机布局和 PWA 外壳。
- 在手机和桌面使用同一套响应式界面；通过 HTTPS 添加到 iOS/Android 主屏幕后，以独立窗口启动。
- MVP 用可编辑的演示身体状态；真实 Whoop/Apple Health 授权接入放到后续阶段。
